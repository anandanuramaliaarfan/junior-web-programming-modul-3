# Ruang Produktif – Task Manager

## Deskripsi
Ruang Produktif merupakan aplikasi manajemen daftar tugas sederhana berbasis web yang dibuat menggunakan HTML, CSS, dan JavaScript.

Aplikasi ini membantu pengguna mencatat, mengelola, mencari, dan memantau status penyelesaian tugas sehari-hari.

Proyek ini dibuat sebagai bagian dari tugas individu Modul 3 Junior Web Programming.

## Fitur Aplikasi
- Menampilkan daftar tugas.
- Menambahkan tugas baru.
- Menghapus tugas.
- Mengubah status tugas menjadi selesai atau belum selesai.
- Mencari tugas berdasarkan nama.
- Validasi input agar nama dan kategori tugas tidak kosong.
- Menampilkan ringkasan jumlah tugas selesai dan belum selesai melalui Console.

## Teknologi yang Digunakan
- HTML5
- CSS3
- JavaScript

## Konsep JavaScript yang Diterapkan
- Array dan Object untuk menyimpan data tugas.
- Function untuk membagi program menjadi beberapa fungsi.
- Conditional Statement (`if/else` dan `switch`).
- Looping (`for` dan `forEach`).
- Array Methods (`map`, `find`, `findIndex`, `filter`).
- DOM Manipulation.
- Event Listener.
- Validasi input.
- Konsep DRY (Don't Repeat Yourself).

## Cara Menjalankan Aplikasi
1. Clone atau download repository ini.
2. Buka folder proyek menggunakan Visual Studio Code.
3. Jalankan file `index.html` menggunakan Live Server.
4. Aplikasi siap digunakan melalui browser.
